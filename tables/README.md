# Demonstration results

These tables show growth classification and concentration-series results for the demonstration data.

Run `ast-reproduce --mode saved --output outputs/demo` to regenerate `classification.tsv`, `mic_series.tsv`, `mic_counts.tsv`, `summary.json` and `provenance.json`. The saved scores come from the training run recorded in `fit_summary.tsv`. Train the model to generate checkpoint files.
