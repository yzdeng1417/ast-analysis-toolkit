# Antimicrobial Susceptibility Analysis Toolkit

Python tools for antimicrobial susceptibility analysis, grouped model evaluation and concentration-series reporting.

**Version 1.0** includes **pseudonymized and numerically perturbed demonstration data**（名称替换、数值扰动后的演示数据）. The data support learning and testing the software. They are not original measurements, a paper reproduction dataset, independently generated synthetic data, or evidence of clinical performance. Name replacement and small numerical changes do not guarantee anonymity or prevent linkage to other copies.

## Install and run

Use Python 3.12 or later. From the source repository:

```sh
python -m pip install .
ast-reproduce --mode saved --output outputs/demo
```

Alternatively, install the wheel from [release 1.0](https://github.com/yzdeng1417/ast-analysis-toolkit/releases/tag/1.0):

```sh
python -m pip install ast_analysis_toolkit-1.0-py3-none-any.whl
ast-reproduce --mode saved --output outputs/demo
```

Choose a new output directory for each run. The command produces:

| File | Contents |
| --- | --- |
| `classification.tsv` | Growth classification metrics for the demonstration subsets |
| `mic_series.tsv` | Concentration-series endpoint estimates and comparisons |
| `mic_counts.tsv`, `summary.json` | Counts from those demonstration calculations |
| `provenance.json` | Input checksums, execution mode and data status |

The saved full-model scores were generated by fresh training on the bundled transformed inputs. All [example results](tables/) were recalculated from those scores. Historical predictions, alternative-model comparisons and research result tables are not distributed.

## Retrain the demonstration model

Training uses Python **3.12.11**, CPU execution and the pinned dependency versions. Install them in a separate environment:

```sh
python -m pip install -r requirements-train.txt
python -m pip install .
ast-reproduce --mode train --output outputs/trained-demo
```

Five grouped outer folds and five ensemble members generate development out-of-fold predictions. Five final members generate evaluation-subset predictions. The supplied row roles keep each isolate group together across optimizer, early-stopping and validation partitions. Training writes model checkpoints, fitting logs and newly calculated full-model results; it does not combine them with historical scores.

The classification threshold is fixed at 0.5 for demonstration. Both the source workflow and evaluation subset were previously examined, so these examples are not untouched clinical validation. Exact model scores may depend on hardware and numerical libraries even with deterministic settings. See the [protocol](src/cmp/data/demo/protocol.json).

## Data and examples

| Resource | Purpose |
| --- | --- |
| [Demonstration inputs](src/cmp/data/demo/) | Transformed paired measurements, retained binary labels, categorical context and grouped row assignments |
| [Demonstration results](tables/) | Recalculated classification and concentration-series results for the full model |
| [Blank collection template](templates/interlaboratory-data-collection/) | Fields for recording new measurements and independent references |
| [Input and result checksums](input_sha256.json) | Integrity checks for this public copy |

Drug names use `Example_Drug_A`, `Example_Drug_B`, etc.（示例药 A、B 等）. Species, strains, specimens, participant groups and well identifiers use consistent example names. Combination-drug contexts join the relevant example components with `+`. Feature column names use the same example drug and species codes.

Binary labels, one-hot indicators, row order, grouping, missingness, elapsed-time settings, dilution concentrations and discrete comparison MIC values are retained. Continuous paired-channel readings are numerically perturbed. The retained comparator values exercise the comparison functions; they are not newly measured validation references. The public release does not include name mappings, perturbation rules, original-value comparisons or private research audits.

`row_index0` links each well to its feature-matrix row. `row_id` links predictions and series membership. Shared no-drug controls remain shared and count once in classification. The development subset uses replicate consensus, and the evaluation subset uses three-replicate majority calls. Endpoint and off-scale comparison rules are explicit in [mic_rules.py](src/cmp/mic_rules.py); all displayed results are demonstrations.
